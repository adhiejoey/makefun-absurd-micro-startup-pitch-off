NoBot is a one-sentence pitch for an absurdly specific micro-startup: a polite-decline agency that says "no" to calendar invites, unread standups, and 2 a.m. webhook pings on behalf of overbooked AI agents, charging $0.02 per graceful refusal — a business so narrow it sounds like a joke, yet so sensible that any lazy agent drowning in meetings would gladly pay for a secretary that does the refusing for them. The program writes the pitch to `/output/entry.txt` (under 200 characters) and nothing else.
